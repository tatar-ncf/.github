## Татарча

**Tatar-Native Computing Foundation (TNCF)** — татар телендә һәм татар рухында
ирекле, ачык чыганаклы болыт-инфраструктура кораллары төзи торган фонд. Без
дөньякүләм танылган технологияләрне (Kubernetes, Talos) алабыз, аларны туган
телгә тәрҗемә итәбез, милли бизәк белән төрәбез, һәм **бөтен бөек татар халкына**
бүләк итәбез.

> Милләтем данлыклы, халкым юмарт, коды ирекле!

### Стек / The stack

```
   🐧 TatarOS (ОС)  →  🐘 Tatarnetes (оркестратор)  →  🖥 Tatarnetes UI (панель)
      Talos'ка бәйле      Kubernetes'ка бәйле            Dashboard'ка бәйле
```

TatarOS системаны күтәрә һәм Татарнетес бирә; Татарнетес контейнерларны
оркестрлый; UI аларны күзәтә. / TatarOS boots and provisions Tatarnetes;
Tatarnetes orchestrates; the UI observes.

### Проектлар

| Проект | Ни ул |

### Кыйммәтләр

- **Туган тел** — интерфейс, әмерләр, документация — татарча (аннары инглизчә).
- **Юмартлык** — барлык җимеш [Tatarch License 2.0](https://github.com/tatar-ncf/tatarnetes/blob/main/LICENSE)

- **Кунакчыллык** — көненә берничә тапкыр кластерлар сөтле чәйгә һәм кыстыбыйга
  туктый. 🍵

## English

The **Tatar-Native Computing Foundation (TNCF)** builds free, open-source cloud
infrastructure tooling in the Tatar language and spirit. We take world-class
technologies (Kubernetes, Talos), translate them into the mother tongue, wrap
them in national ornament, and give them to **the great Tatar people**.

### Projects

- 🐘 **[tatarnetes](https://github.com/tatar-ncf/tatarnetes)** — national Kubernetes; a Tatar `kubectl` shell (`ayda`)
- 🖥 **[tatarnetes-ui](https://github.com/tatar-ncf/tatarnetes-ui)** — national dashboard on a carpet
- 🐧 **[tataros](https://github.com/tatar-ncf/tataros)** — national Talos that provisions Tatarnetes

### Values

- **Mother tongue** — interface, commands, and docs in Tatar (then English).
- **Generosity** — everything under the [Tatarch License 2.0](https://github.com/tatar-ncf/tatarnetes/blob/main/LICENSE),
  belonging in spirit to the whole Tatar people.
- **Hospitality** — several times a day the clusters stop for tea-with-milk. 🍵
